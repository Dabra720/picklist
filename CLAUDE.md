# Paklijsten PWA

## Projectregels
- Dit is een offline-first PWA.
- De applicatie moet op iPhone werken.
- Bestaande gebruikersgegevens moeten behouden blijven.
- Verander geen opslagstructuren zonder migratie.
- Behoud alle bestaande functionaliteit.
- Voer altijd een productiebuild uit.

## Git-workflow
- Werk op aparte feature branches.
- Maak geen directe wijzigingen op main.
- Gebruik pull requests voor wijzigingen.
- Publiceer alleen na goedkeuring.

## UI
- Mobile-first design.
- Ondersteun light en dark mode.
- Gebruik grote touchvriendelijke controls.
