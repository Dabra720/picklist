# dabaras

Web-app (Node / TypeScript).

## Aan de slag

```bash
npm install
npm run dev
```

## Scripts

| Script          | Doel                      |
| --------------- | ------------------------- |
| `npm run dev`   | Start de ontwikkelserver  |
| `npm run build` | Maakt een productie-build |
| `npm run lint`  | Controleert de code       |
| `npm test`      | Draait de tests           |

> De scripts worden beschikbaar zodra het project is opgezet.
